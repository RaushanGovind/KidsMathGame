🎯 Quick Start Guide

  1. Open the Game: Double-click on index.html
  2. Use Bubble Matrix: Click bubbles to select (watch colorful animations!)
  3. Reset Bubbles: Click the red "Reset Bubbles" button
  4. Choose Addition Type: Click Menu → Addition → Select a button (e.g., "2 × 2")
  5. Practice Math: Solve the problems and check your answers!
